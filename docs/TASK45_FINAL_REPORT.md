## B. Architecture and execution flow (as actually implemented)

- **Entry point** — `run.py` dispatches to `src/cli.py` via a `TASKS` dict. Confirmed
  targets: `setup/registry`, `seed-universe`, `lookup`, `live`, `run`, `run-sample`,
  `score`, `test`, `web`, `demo`, `clean`. **There is no `evaluate` target** — the
  evaluator is `python -m src.evaluate`.
- **Pipeline** — `pipeline.run()` → `process_company()` in 7 layers: registry →
  location → web discovery → extraction → verification → explanation/change-detection
  → **resumability carry-forward**.
- **Registry** — `registry.BrregClient` over the shared `HttpClient`;
  `REGISTRY_FACTS` is the single field-table source.
- **Web discovery** — `sitefinder.SiteFinder` (batch) and `liveweb` (live agent);
  `normalize.DIRECTORY_HOSTS` is the one canonical deny list.
- **Identity gate** — `gate.evaluate_page()`; `is_directory_host()` is checked at
  **`gate.py:166`, before** the `org.value in found` acceptance at line 182.
- **Budget manager** — `budget.RunBudget` (one `threading.RLock`); `net.Budget` is a
  facade; `HttpClient.get` calls `begin()` before the socket.
- **Persistence** — `profiles.Profile.write()` and `RunReport.write()` both
  temp-file → `fsync` → `os.replace`.
- **Report** — `RunReport.finalise()` folds §7 fields from real results + `to_dict()`
  budget.
- **Evaluation/scoring** — `src/evaluate.py` scores on-disk profiles;
  `src/score_local.py` applies fixed 50/30/12/8 weights, threshold 65.

## I. Score discrepancy (78.2 → 78.8 → 78.3)

**Determined mechanism, not hypothesis:** `run.py score` computes against the **live
`profiles/` directory**. Scoring weights (`recall 50 / precision 30 / synthesis 12 /
ease_of_use 8`) and `QUALIFY_TOTAL=65` are hardcoded constants; the golden set is
unchanged at 12 files. The corpus is not frozen — it grew to **2,146** profiles with
**649 rewritten today after 14:00** by verification runs. Recall is a ratio
(`filled / (profiles × fields)`), so adding profiles with lower field density moves
the number while *precision stays pinned at 100%* — exactly what was observed.

**Hypothesis-quality caveat:** historical corpus snapshots were overwritten, so the
exact 78.2↔78.8 attribution is inferred from the constants and the growth evidence,
**not** from saved before/after copies. **The current score (78.3) is reproducible
only while the corpus is untouched.** No scoring logic was changed.
