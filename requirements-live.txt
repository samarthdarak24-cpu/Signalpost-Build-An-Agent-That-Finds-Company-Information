# Optional live layer for Signalpost (Phase 1).
#
# These are NOT needed by the competition agent itself. `python run.py run`,
# `run.py score` and `run.py web` all stay standard-library only, so the judged
# artifact keeps its zero-install property. This file is only for the separate
# real-time bridge described in docs/LIVE_DATA_STACK.md.
#
# Verified working end to end on 2026-10-10:
#
#   python -m venv .venv-live
#   .venv-live/Scripts/python.exe -m pip install -r requirements-live.txt
#   .venv-live/Scripts/python.exe -m uvicorn src.live_api:app --port 8799
#
# Then open the console (`python run.py web`, port 8787) and go to
# Live Research -> "Live registry changes". The panel streams from the bridge.
#
# If the bridge is not running the panel says so; it does not silently show
# "no changes", which would be a lie about the world rather than about the setup.
